# Maintainer response templates

These are optional human-edited messages, not automatic mass replies.

## Reproducible bug report received

Thanks for the detailed report. I can see the reported version and steps. Could
you also share the OS/architecture, input/output codec names and a minimal
reproduction with a generated file? Please avoid private media and redact
personal paths or credentials from any logs.

## Need a smaller first PR

Thanks for being interested in contributing. This task reaches several
platforms, so it may not be a good first issue. The contributor FAQ explains the
docs-only workflow. Could you start with one narrow change and show the
formatting check result? We can review the next step after the small PR.

## New PR received

Thanks for putting this together. The problem statement and test results make
review much easier. I'll compare the behavior with the issue's acceptance
criteria and leave specific review feedback. Review depends on volunteer
availability and merging is not guaranteed.

## Reproduction incomplete

I cannot reproduce this with the information currently provided. Please include
exact release/version, OS and architecture, expected versus actual result, a
safe sample/codec description and steps. If this concerns security or privacy
leakage, report privately according to SECURITY.md rather than posting public
details.

## First-time contributor recognition

With the contributor's permission, we can thank them in a monthly project
update, linking their accepted PR. Do not publish personal details or
recognition without consent; never invent participation.
