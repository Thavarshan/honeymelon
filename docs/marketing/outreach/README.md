# Ethical outreach and launch gates

**Status:** Research and drafts prepared 2026-11-09. No outside posts sent.

This is not a calendar-driven release announcement. Publication and feedback
collection need the maintainer's approved identity, the chosen venue's current
rules and actual launch readiness. GitHub Discussions is disabled in this repo;
use an issue or a genuine PR discussion rather than an invented discussion URL.

## Verified platform-wide policies

- [Reddit spam policy](https://support.reddithelp.com/hc/en-us/articles/28012014962580-How-do-I-keep-spam-out-of-my-community):
  promotion is not automatically spam, but each subreddit may ban it or apply
  other restrictions, and repetitive unwanted posting is prohibited.
- [Reddit rules](https://support.reddithelp.com/hc/en-us/articles/360043503951-What-are-Reddit-s-rules):
  community-specific posting rules apply in addition to site rules.
- [DEV Terms](https://dev.to/terms): substantive, original posts must not be
  primarily backlink or promotional schemes; full content should be on DEV.
- [DEV code of conduct](https://dev.to/code-of-conduct): cite sources and
  disclose AI assistance when required by their guidelines.
- [Show HN policy](https://news.ycombinator.com/showhn.html): share something
  personally built and actually usable, not a landing page or generic article.
- [Hacker News guidelines](https://news.ycombinator.com/newsguidelines.html):
  avoid using HN primarily for promotion, generated submissions, automated
  posting or soliciting votes.
- [Product Hunt guide](https://help.producthunt.com/en/articles/17350772-launch-guide):
  submit from a real personal account and prepare a working product, visuals,
  accessible copy, and a genuine maker comment.
- [Product Hunt promotion restrictions](https://help.producthunt.com/en/articles/17734384-5-how-to-promote-your-launch-and-what-to-avoid):
  never request/buy upvotes, spam DMs or use fake accounts.
- [GitHub acceptable use](https://docs.github.com/en/site-policy/acceptable-use-policies/github-acceptable-use-policies):
  do not post bulk promotions into other repositories or create fake engagement.

All linked guidance should be checked again before actual publication.

## Channel ledger and sequence

See [outreach-ledger.csv](outreach-ledger.csv) for candidates, links, rules,
draft topics, status and results. Candidate is **not permission to post**. For
subreddit-specific rules, a moderator or current rules page check remains
mandatory. Do not assume a global Reddit 10% self-promotion rule is a permit.

The initial low-risk work is:

1. Provide genuine help on a specific file conversion or TypeScript question
   without a Honeymelon link unless relevant and allowed.
2. Publish a useful full technical article on DEV after a claims review.
3. Request feedback from real beta testers who opted into discussing the app.
4. Use official launch venues only once installer, demo, download, support,
   website and browser release gates have the required evidence.

No automated posting, identical cross-posts, paid media, purchased upvotes,
sockpuppets, misleading testimonials or bulk unsolicited DMs.

- [ ] Feedback triage coverage available for several days after publication.

If any gate fails, use an educational conversation or an honest private review
request, not a public product-launch claim.

## Feedback, moderation and response plan

Collect only actionable reports: OS/architecture, exact release, source and
output formats, expected and actual behavior, synthetic reproduction and
relevant safely redacted error text. Never request private media.

Track substantive questions, moderator feedback and fixes as GitHub issues, with
the platform URL only when permitted. Acknowledge criticism respectfully without
debating a user's lived experience. If a supported conversion fails, link a
reproduction and investigate instead of repeating marketing claims.

For a report of security/privacy leakage, stop distribution of the affected
claim, direct details to the private security policy, and review the launch
gate. For broken links or incorrect releases, correct/withdraw the post.

Do not share personal identities, screenshots or direct quotes from testers
without permission. Do not estimate attribution where analytics are absent.
