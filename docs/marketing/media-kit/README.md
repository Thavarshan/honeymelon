# Honeymelon media kit

**Status:** Source materials prepared for maintainer review on 2026-11-09.
This is not proof of a completed recorded demo or a released browser app.

## What exists

- The product name is Honeymelon. Older published binaries retain Comet names.
- The current stable desktop release is **v2.2.3** (2024-11-07).
- The separate desktop **v3.0.0-beta.1** (2026-10-18) is unsigned.
- The React screenshots in `assets/screenshots` show the **beta**, not stable.
- No verified stable v2.2.3 screenshot is presently in this media kit.
- The desktop beta's twelve published binary assets have GitHub SHA-256 digests.
- The stable release's published assets currently lack API digest metadata.
- Honeymelon Web source exists but public launch remains gated by #85.

## Must verify before distribution

- Record the actual desktop beta flow on a supported device with synthetic media.
- Confirm the shot names, actions, destination and captions match the installed UI.
- Produce a real 30–45-second video, not a slideshow advertised as product proof.
- Confirm any stable-version screenshot separately using the stable binary.
- Verify the desired platform and release installers and published checksums.
- Beta macOS and Windows installers are not signed or notarized.
- Confirm the public homepage and each CTA are actually live.
- Obtain owner permission before publishing on any external channel.

**Never** suggest the current stable release has the beta React UI, that all
codecs work everywhere, or that browser conversion is publicly available.
