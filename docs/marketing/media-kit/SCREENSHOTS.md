## Filename and identity caveat

Although the repository is Honeymelon today, both the 2024 stable assets and
2026 beta assets retain Comet filenames. Do not rename downloaded binaries,
publish invented checksums, or imply that old releases have been replaced.

Screenshots may be used in the README with source/version captions. Obtain owner
approval and document any edits before external publishing.
