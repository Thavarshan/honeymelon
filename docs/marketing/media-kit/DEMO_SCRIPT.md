# Desktop beta demo: 30–45 seconds

**Status:** Storyboard and caption script only. No recorded video exists here.

**Build to record:** v3.0.0-beta.1, unsigned, on a supported desktop OS. Use
generated/demo media without recognizable people, copyrighted songs or private
content. Prefer a generated small PNG for the shortest reproducible flow; verify
that the output option exists in that particular installed build.

## Storyboard

| Time    | On-screen action                                    | Caption / voiceover                                            |
| ------- | --------------------------------------------------- | -------------------------------------------------------------- |
| 0–5 s   | Show the installed app and version, with beta badge | "Honeymelon 3.0 desktop beta converts files on your computer." |
| 5–12 s  | Add a synthetic image from a local folder           | "Choose a local file. No account or upload is required."       |
| 12–20 s | Choose the supported image output and destination   | "Pick an output the installed build supports."                 |
| 20–31 s | Click Convert; let real progress reach Complete     | "The conversion runs locally. This example is a small image."  |
| 31–39 s | Reveal the generated file in its folder; open it    | "Find and inspect the converted file. Your original remains."  |
| 39–45 s | Show official beta releases and unsigned warning    | "Try the unsigned beta and send us reproducible feedback."     |

## Recording checks

- Use the real application and **one continuous successful conversion**.
- Verify original file remains intact and new file opens correctly.
- Keep the cursor and important interface controls in frame.
- Add actual burned-in captions or distribute matching subtitle text.
- Do not simulate progress or replace a failed result with a stock screenshot.
- Keep a downloadable source project and the generated synthetic input.
- If this takes over 45 seconds, adjust the storyboard rather than speed up a
  conversion to pretend it is faster than observed.

## Release disclaimer

The current stable desktop release remains v2.2.3 and has a different UI. Beta
macOS and Windows builds are unsigned and may display OS trust warnings. Use the
[official beta release](https://github.com/Thavarshan/honeymelon/releases/tag/v3.0.0-beta.1)
and verify its published SHA256SUMS before installing. This clip does not
demonstrate unreleased Honeymelon Web capabilities.
